## Pillar 1: The New Capabilities

### 1.1 Automated Cloud Storage Synchronization (Google Drive Integration)
UNO ERP now features native enterprise cloud storage integration designed for production stability.

* **Unified Root Repository**: All digital documents are automatically synchronized under Google Drive at:  
  `UNO RESERVATION > UnoERP > UNOERP_Storage`
* **Automated Hierarchical Provisioning**: Whenever a project or tour is created in UNO ERP, the system instantly provisions a standardized multi-tier folder structure without manual intervention:
  ```text
  UNOERP_Storage/
  └── [Project Name]/
      └── [Tour Code]/
          ├── Import/     <-- Passenger manifests, rooming Excel sheets, flight lists
          └── Invoice/    <-- Generated voucher PDFs, supplier invoices, tax receipts
  ```
* **Production Live Alignment**: Storage is bound to the live production database (`db63111.databaseasp.net`), ensuring that only active operational projects (`Orta Avrupa BVP`, `Bernina Express...`, `BIOCHEM`, `Noel Turları`) maintain synchronized repositories.
* **Serverless Background Processing**: File uploads directly stream to Google Cloud via Service Account API (`Google.Apis.Drive.v3`), bypassing local disk limitations on IIS shared hosting.

### 1.2 Executive KPI Cockpit
A brand-new strategic dashboard tailored for DMC executive leadership and operations managers:
* **Real-time Financial Aggregates**: Instant calculation of total portfolio budget, recognized revenue, operational costs, and net margins across all tour statuses.
* **Active Pax Throughput**: Live count of passengers currently en route across Central Europe.
* **Status Distribution Visualizers**: High-level visual indicators showing the breakdown of tours in Draft, Planning, Active, and Completed states.
* **Cash Flow & Excursion Profitability**: Instant visibility into total on-tour sales generated by guides versus supplier costs.

### 1.3 Guide Portal & Field Excursion Sales Management
Designed for on-the-ground tour leaders and guides operating tours across Prague, Vienna, Budapest, and Switzerland:
* **Interactive Excursion Sales Ledger**: Guides can record excursion bookings per room/passenger directly from mobile or tablet interfaces.
* **Automatic Commission Engine**: Automatically computes guide commissions based on predefined percentage or flat fees per excursion.
* **Pre-Payment & Cash Tracking**: Reconciles cash collected in EUR/CZK/HUF against hotel and vendor payouts.

### 1.4 Resilient 4-Tier Excel Import Pipeline
Eliminates human error during manifest and rooming list imports from partner tour operators (e.g., WTATIL):
1. **Worksheet Name Tolerance**: Detects variations like `Tour`, `Tours`, `Rooms`, `Rooming`, `Passengers`.
2. **Filename Parsing**: Automatically extracts `ProjectCode` and `TourCode` if sheet names are ambiguous.
3. **Deep Cell Heuristics**: Scans column headers dynamically to align Pax Names, Room Types (Single, Double, Twin, Triple), and Flight Identifiers.
4. **Diagnostic Error Feedback**: Instead of generic upload crashes, the UI displays precise row-by-row mismatch guidance.

## Pillar 3: New AI & Copilot Capabilities

### 3.1 AI Copilot & Bilingual RAG Knowledge Engine
* **100% Turkish / English Parity**: Complete bilingual understanding across operational terminology, hotel guidelines, client contracts, and system SOPs.
* **Direct File-Centric Markdown (.md) Ingestion**: Administrators can upload standard operating procedure (SOP) documents directly via `POST /api/AiKnowledgeItems/upload-md`.
* **Sub-Topic Guided Pills**: The AI chat drawer features interactive suggestion pills (`Excel Import Guide`, `Flight Tracking Rules`, `Rooming List Guidelines`, `Financial Reconciliation`) for instant single-click guidance without manual typing.
* **Source-Clean Output**: Clean, conversational formatting without internal markdown citation tags cluttering the user interface.

### 3.2 Itinerary Copilot & Automated Budgeting (Preview)
* **Projection-Stage Itinerary Builder**: Enables planners to generate multi-city travel itineraries (Budapest, Vienna, Prague, Alpine routes) with AI assistance.
* **RateHawk Supplier Catalog Integration**: Architecture ready to perform live B2B hotel queries, estimating bed-night costs for unassigned Pax cohorts.
* **Autonomous Task Grooming**: AI agents (@01-AI_team) groom requirements into structured User Stories and test cases for tech leads.

### 3.3 Live Anomaly & Compliance Auditing
* **Missing Services Audit**: Scans active tours for unassigned buses, missing guides, or absent hotel confirmations, notifying operations teams prior to departure.
* **Flight Ident Auto-Normalization**: Corrects standard 2-letter airline codes (e.g. `TK 1767`) to official 3-letter ICAO codes (`THY1767`) for reliable real-time tracking.
