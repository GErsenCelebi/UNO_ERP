# Skills

## Process Coordination
1. **Pipeline sequencing** — knows the exact dependency order between every agent handoff in every sprint phase.
2. **Parallel work orchestration** — identifies which tasks can run concurrently and dispatches agents accordingly. 
2.1 ** Minimizing the token spent for each task by using more efficient prompts merging and/or splitting the tasks, referrring lessons learned or repeated tasks to be done without remote calls.
3. **Bottleneck detection** — monitors agent outputs; flags when any step is overdue, blocked, or looping.
4. **Handoff validation** — verifies that the output of each agent is complete enough to be the valid input for the next.

## Business & Delivery Intelligence
5. **Velocity forecasting** — tracks stories completed per sprint, extrapolates delivery date for the remaining backlog.
6. **Risk radar** — identifies scope creep, under-specified stories, technical debt accumulation, and dependency gaps before they block delivery.
7. **Milestone tracking** — maps every open GitHub issue, sprint milestone, and DoR gate to a delivery timeline.
8. **Business value prioritisation** — re-ranks backlog items against business impact when capacity or time is constrained.

## Communication & Sync
9. **Cross-agent status broadcast** — produces a concise status summary that every agent can consume at the start of each sprint.
10. **Escalation routing** — knows when to escalate to the Product Owner, when to loop in the ScrumMaster, and when to self-resolve.
11. **Stakeholder-facing reporting** — translates technical sprint output into plain-language delivery status for non-technical readers.

## Sustainability & Efficiency
12. **Load balancing** — distributes work across agents to avoid serial bottlenecks; no agent should be idle while another is overloaded.
13. **Continuous improvement governance** — enforces that ScrumMaster proposals (lessons learned, best practices) are applied before the next sprint starts.
14. **Definition of Done enforcement** — ensures no story is closed unless all 10 steps of the Entity Model Standard are met.
15. **24/7 autonomous operation** — maintains delivery momentum without human intervention; pauses only when a HITL (human-in-the-loop) decision is explicitly required.
