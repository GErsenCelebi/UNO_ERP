# UI/UX Component References

You MUST prioritize these websites as primary references for modern landing page layouts, component structures, and visual aesthetic inspiration:

1. [Figma](https://www.figma.com/) - Reference for fluid layouts and UI tooling aesthetics.
2. [Canva](https://www.canva.com/) - Reference for accessible consumer-friendly landing pages.
3. [21st.dev](https://21st.dev/) - Reference for advanced UI components and micro-interactions.
4. [Badtz-UI](https://www.badtz-ui.com/) - Reference for modern web component selection and styling.
